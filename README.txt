WICHTIG:
Nicht index.html doppelklicken. Three.js-Module benötigen einen HTTP-Server.
Windows: START_WINDOWS.bat doppelklicken.
Mac/Linux: START_MAC_LINUX.command ausführen.
Alternativ im Ordner:
  python -m http.server 8000
und dann http://127.0.0.1:8000 öffnen.

Die Website lädt Three.js 0.186.0 vom jsDelivr-CDN.
Für einen echten öffentlichen Betrieb sollte die Abhängigkeit später lokal gebündelt bzw. mit einem Build-System wie Vite gebaut werden.
